# Primitive families in the native edit language

## Operational criterion

Use the attained states, named measurements and elementary edit relation of [RoleBridge.md](RoleBridge.md). Composition is finite concatenation of elementary edits with matching intermediate states at the same native tolerance. The reachability relation includes the empty path. Use every positive rational tolerance from the original theorem.

A uniform primitive command uses one mutation mode of that relation and one writable part of the native experimental record. In the local mode the command changes the prepared probability table at fixed capabilities. In the cover mode the writable part is one capability of the experiment: positive proposal support, the timed decision schedule, the license catalogue or the receipt catalogue. Legality, attainedness, the cover condition and the original law-preservation conditions are checked in the underlying relation. A family offers all legal instances of its command.

For the decision schedule the command writes the available decisions at a supplied clock grade. This is a single indexed field write, with the rest of the schedule and all other readouts fixed. A family may declare a domain for that grade parameter, fixed before seeing the law or tolerance. It may therefore offer a common command at a subset of the native grades. Lawfulness of an invocation is still decided in the original experiment, including all nesting, audit and terminal tests. The other command modes have no clock parameter. This criterion uses the two mutation modes of the unlabelled relation and the independently typed fields of the query record.

A catalogue is complete if it generates the same reachability relation as the elementary edits. It is a basis if every family is essential to this generation. Two families have the same experimental meaning when they admit the same edits after comparing native query tables at the given tolerance. In particular a parameter is visible to the operation through its named query position. Matching presentations preserve that position and the boundary grade.

## Result

With this criterion, canonicality of the six-family basis fails. The uniform clock catalogue has five families. It offers exactly the original elementary edit relation for every experiment in the class, every finite clock and every rational tolerance. The six-family catalogue with separate earlier and terminal domains offers the very same elementary relation. The coupled two-grade experiment has precisely these two irredundant bases at every positive tolerance, and the five-family one is the unique minimum-size complete catalogue there. Because it generates the entire class and the coupled experiment supplies the lower bound, five is also the minimum number of families needed to cover the class in this command language.

The two catalogues have a bijection of invocations preserving each native position. In particular, the timed test distinguishes the two decision edits in either catalogue. If equivalence requires a matching of families, their cardinalities already rule out equivalence. If equivalence matches invocations and experiments instead, the two catalogues are equivalent representations with different family counts. The count of six at the level of families cannot follow from these tests and the composition of their elementary edits alone.

## Uniform implementation at every clock grade

An elementary edit addresses a native position. For the local mode the detector is equality of the two capability profiles. The support, license and receipt positions are detected by a strict change of the corresponding tested data. A decision position at grade j is detected by a change of the available decisions there. Apply these detectors only to the already specified elementary relation on attained query tables.

The existing cover proof identifies the single writable capability of a cover. Its argument for decisions uses nesting, attainedness and the latest changed grade, so it gives a single changed grade inside the clock field. Use the bidirectional correspondence between the observation partition and its available binary decisions to translate this to the measured data. These arguments establish existence and uniqueness of the native position for each elementary edit. If the position is a decision at grade j, the prepared law, licenses and receipts stay fixed and all other grades agree. Thus the entire new query table is the result of overwriting the j-entry of the old decision table with the new one. Conversely, any strict change of that form between attained states that satisfies the capability-cover condition is an elementary edit at j. This is the same update formula and the same test of a cover at every j. The terminal grade is special in the tests for attainedness of states, which this command applies unchanged.

Recover the old effect labels by inspecting this position. For a decision position, compare its native grade with the last grade. The uniform clock catalogue provides that same indexed write at all grades. The split catalogue provides it on the domain of earlier grades and on the singleton terminal domain. A grade-parameterized invocation still writes just one table entry. On the coupled example, the state with both decisions hidden reaches the state with both disclosed in the uniform catalogue. It cannot do so by a single invocation, because the two states differ at both grades. The endpoint readouts, timed tests, retained licenses and audit checks are the same ones used before. ## Composition and essential families

Call a position live at ε if some nonidentity elementary edit addresses it at that tolerance. A catalogue generates every native ε-chain exactly when it offers every live position. Sufficiency replaces every nonidentity step by an offered invocation at its unique position and uses the empty path for identities. Necessity uses the following stronger argument on a live pair. A path missing a decision position preserves the partition at that grade, even if it edits other grades. Omitting the support, license or receipt position preserves the corresponding observable through composition. For a nonidentity local change the capabilities agree at both ends. A strict support contraction cannot intervene along a path with those endpoints, since support contracts monotonically. With the local position omitted the remaining edits fix the law, contradicting the specified local change. This argument handles local law changes with equal projected laws as well.

Apply the same criterion after erasing a family. An irredundant basis therefore covers all live positions and each family offers at least one live position offered by no other family. This is an exact characterization for any attained experiment and clock size under the command criterion above, including instances with inactive positions and overlapping parameter domains. [FamilyBasis.lean](MovingProjection/FamilyBasis.lean)

At every positive tolerance, each of the four nonclock positions and both decision positions are live on the coupled source. This follows from the earlier indispensability witnesses and the correspondence between positions and effects on a two-grade clock. Coverage forces the four nonclock families and at least one clock family. If the full two-grade domain is offered, every other clock family lacks a private live position. If that domain is absent, each nonempty clock domain is a singleton and coverage forces both singletons. Conversely both catalogues pass the coverage and private-position checks. This proves the classification even if arbitrary overlaps of declared clock domains were allowed in the definition. Any complete catalogue with fewer than five misses a live position. A complete catalogue with exactly five is irredundant and hence is the uniform one.

In the uniform and split catalogues each position belongs to a unique family. Reassign each invocation in either direction to the unique family offering its position, preserving the grade and every endpoint. This gives a bijection before checking any final reachability claim. As the same position between the same attained states has the same elementary legality, the reparameterization preserves every elementary edit and each composable sequence under the original tolerance. The original signed-core criterion and the fixed-tolerance obstruction therefore still apply. Equality of the native query tables under recoding also preserves each individual invocation. ## The additional condition that forces a terminal split

Consider a client contract in which the family name alone determines whether a successful invocation changes the terminal decision readout. This is a condition on actual measured effects across all allowed arguments and attained endpoints. It requires more than the original availability rule, which lets a client see the supplied grade. By uniqueness of the changed position, the split catalogue satisfies this contract on every clock. The two live decision writes on the coupled source show that the uniform catalogue fails it. The classification above then implies that the split catalogue is the unique irredundant basis on that source among catalogues satisfying the additional contract. This identifies a precise way to recover six and supplies a control showing the contract has independent force. [PrimitiveBasis.lean](MovingProjection/PrimitiveBasis.lean)
